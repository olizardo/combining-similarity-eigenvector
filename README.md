# A Generalized Approach to Combining Similarity and Eigenvector Analysis of Networks

This repository contains the complete replication materials—code and reproducible computational pipeline—for the paper **"A Generalized Approach to Combining Similarity and Eigenvector Analysis of Networks"** by Omar Lizardo (Connections, 2026). The full analysis is a single self-contained R script (`analysis.R`).

The manuscript, galley proofs, and revision materials are maintained separately (locally and on Overleaf) and are not part of this repository.

The paper implements a generalized framework that combines pairwise node similarity measures (such as Jaccard similarity) with feedback centralities (such as Bonacich's eigenvector scores), allowing for analyses that range from pure brokerage (dissimilarity-weighted) to pure closure (similarity-weighted), as well as hybrid configurations. The classic **Florentine Families network** (Padgett & Ansell, 1993; Breiger & Pattison, 1986 version, combining marriage and business ties) is used as the empirical case study.

## 📂 Repository Structure

The project directory is structured as follows:

```text
├── analysis.R                      # Main replication script (primary entry point)
├── Functions/
│   └── prestige_sim.R              # Generalized similarity/eigenvector scoring function (Algorithm 2)
├── Plots/                          # Rendered manuscript figures (regenerated by analysis.R)

│   └── bump.png                    # Figure 2: parameter sensitivity bump chart
├── Tables/
│   └── table1.tex                  # Table 1: eigenvector-based scores under four weightings
├── parameter.csv                   # Raw sensitivity-analysis scores (beta grid)
├── renv.lock                       # renv lockfile pinning exact package versions
└── renv/                           # renv infrastructure (project library is NOT tracked)
```

## 🛠️ Prerequisites & Installation

You will need **R** (4.5 or later). Dependencies are managed with `renv`.

```R
renv::restore()
```

This installs all locked CRAN dependencies, the `ggbump` package from GitHub, and the `networkdata` package (the source of the Florentine Families data), so no separate data files are required.

---

## 🚀 How to Reproduce the Findings

1. **Clone the repository** and open it as a project in your editor (RStudio or Positron), or `setwd()` to the project root.
2. **Restore dependencies** with `renv::restore()` (above).
3. **Run the pipeline**:

   ```R
   source("analysis.R")
   ```

   or from the command line:

   ```bash
   Rscript analysis.R
   ```

The script regenerates both figures (Figure 1 and Figure 2 in the paper), the full numeric results table (Table 1), and the raw sensitivity scores (`parameter.csv`), guaranteeing that the numbers in the paper are exactly what the code computes.

The key function is `prestige_sim(x, a, b)`, which implements Algorithm 2 of the paper: `a = 0, b = 0` recovers standard Bonacich eigenvector centrality; `a = 0, b = 1` recovers the Alvarez-Socorro et al. (2015) dissimilarity-weighted scores; `a = 1, b = 0` gives similarity (closure)-weighted scores; and intermediate values give hybrid brokerage/closure rankings.
