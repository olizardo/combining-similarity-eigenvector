# A Generalized Approach to Combining Similarity and Eigenvector Analysis of Networks

This repository contains the replication materials for the paper **"A Generalized Approach to Combining Similarity and Eigenvector Analysis of Networks"**. This project implements a generalized framework that combines pairwise node similarity measures (such as Jaccard similarity) with feedback centralities (such as Bonacich's eigenvector scores) to allow for analyses that range from pure brokerage (dissimilarity-weighted) to pure closure (similarity-weighted), as well as hybrid configurations.

---

## Repository Structure

The files in this repository are organized as follows:

* **Analysis & Code**:
  * `[analysis.qmd](analysis.qmd)`: The master Quarto document containing the full computational pipeline. It loads the Florentine Families dataset, implements the generalized prestige algorithm, runs the sensitivity analysis, and exports all figures and the main table.
  * `[parameter.csv](parameter.csv)`: Sensitivity analysis raw scores across a range of parameter configurations.
* **Paper & Writing**:
  * `[manuscript.tex](manuscript.tex)`: The LaTeX source document for the main paper.
  * `[references.bib](references.bib)`: BibTeX file containing all academic references cited in the paper.
  * `[asr.bst](asr.bst)`: Academic Sociology Review (ASR) bibliography style file.
  * `[editor-letter.tex](editor-letter.tex)` & `[response-memo.tex](response-memo.tex)`: Revision materials.
* **Generated Outputs** (automatically produced by the pipeline):
  * `[main.tex](main.tex)`: The LaTeX table containing eigenvector-based scores under different configurations, dynamically generated by `[analysis.qmd](analysis.qmd)` and included in the manuscript via `\input{main}`.
  * `[medici.png](medici.png)`: Network plot of the Medici marriage and business ties.
  * `[bump.png](bump.png)`: Sensitivity analysis bump chart showing family rank trajectories across parameter values.
  * `[analysis.html](analysis.html)`: Compiled HTML report of the computational pipeline.
  * `[manuscript.pdf](manuscript.pdf)`: Compiled PDF of the paper manuscript.
* **Reproducibility & Environment**:
  * `[renv.lock](renv.lock)`: The `renv` lockfile capturing the exact package versions used to run the analysis, including packages hosted on CRAN, GitHub, and custom repositories.
  * `[renv/](renv/)`: Project-local R library configuration files.

## Step-by-Step Replication Instructions

To reproduce all tables, figures, and compile the final PDF manuscript, follow these three steps:

### 1. Restore the R Package Environment
This project uses `[renv](https://rstudio.github.io/renv/)` to lock down dependencies. To install the exact package versions required:

1. Open R or Positron inside this project directory.
2. Run the following command in your R console to restore the environment:
   ```R
   renv::restore()
   ```
   This will automatically install all CRAN dependencies, the `ggbump` package from GitHub, and the `networkdata` package from its dedicated repository.

### 2. Run the Computational Pipeline
To re-run the analysis and regenerate the table (`[main.tex](main.tex)`) and figures (`[medici.png](medici.png)` and `[bump.png](bump.png)`):

* **Using the Command Line (Quarto CLI)**:
  ```bash
  quarto render analysis.qmd
  ```
* **Using R**:
  ```R
  quarto::quarto_render("analysis.qmd")
  ```

This step ensures that all tables and figures are updated directly from the code, guaranteeing that the numbers in the paper are exactly what the code computes.

### 3. Compile the PDF Manuscript
Once the tables and figures are generated, you can compile the LaTeX paper:

* **Using R (TinyTeX)**:
  ```R
  tinytex::latexmk("manuscript.tex")
  ```
* **Using the Command Line**:
  ```bash
  pdflatex manuscript.tex
  bibtex manuscript
  pdflatex manuscript.tex
  pdflatex manuscript.tex
  ```
